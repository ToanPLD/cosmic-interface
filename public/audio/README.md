# Hướng Dẫn Cung Cấp File Âm Thanh MP3 Cho Website 20/10

Thư mục này (`public/audio/`) chứa các file nhạc MP3 cho danh sách phát nền của website.
Khi bạn copy các file MP3 vào đây với đúng tên file quy định, trình phát nhạc sẽ tự động nhận diện và phát bài hát trực tiếp offline không cần kết nối mạng.

> **Lưu ý:** Nếu bạn chưa kịp bỏ file nào vào, trang web vẫn sẽ tự động chuyển sang **Giai điệu Hộp nhạc pha lê lãng mạn (Chimes)** tự sinh sẵn có, đảm bảo không bao giờ bị tắt tiếng hay phát sinh lỗi!

## Cách đưa nhạc vào:
1. Bạn tải file audio định dạng `.mp3` từ các link YouTube trên (hoặc dùng các bài hát sẵn có trong máy tính của bạn).
2. Đổi tên file thành đúng tên ở cột **Tên file cần đặt** (ví dụ: `flower.mp3`, `wonderful-u.mp3`, ...).
3. Đặt file vào ngay thư mục này: `d:\Sources\Code\gift\public\audio\`.
4. Mở lại trang web và thưởng thức âm nhạc!
